# v0.9.5 セキュリティ改修

対象は依頼された10項目（アクセスログ、リンク点検、QR、bcrypt、コメント/IP拒否、編集画面の置換上限）です。

## 仕様と移行

| 項目 | 改修内容 |
| --- | --- |
| 1 アクセスログの容量・負荷 | 初期値30日/10万件、全体120件/分、IP共有枠10件/分。設定画面で変更。DBの原子的カウンターと即時取得の排他ロックを使用。カウンターは最大65行。保存件数はID範囲を使って制限し、削除済みIDが多い場合は設定件数より少なく保持する場合があります。上限到達や排他競合時は記録を省略します。 |
| 2 SSRF | 自サイトの許可ホスト、公開IP、HTTP/HTTPS、80/443に限定。認証情報を含むURLを拒否。全DNS応答のIPを確認し、WPの安全なHTTP APIも使用。転送は自動追従せず、最大3回まで各転送先を同条件で再検証。 |
| 3 サイトマップの取得量 | 1応答1MiB、全体20取得/20秒、loc 2万件、同じ子サイトマップの重複取得を除外。圧縮応答とDTD/ENTITYを拒否。XMLエラーを破棄。DNS解決に要する時間自体はOS依存。上限・失敗を管理画面へ表示。 |
| 4 ログの機密情報 | URL/参照元の認証情報・全クエリ・フラグメントを保存前に除去。URL/参照元2048、path 1024、UA 512、IP 45バイトまで。既存ログの画面/CSVも即時に保護し、DBは200件ずつ移行。 |
| 5 QR | MITのNayukiライブラリを同梱。入力・生成・PNGダウンロードはブラウザ内のみ。外部API/CDN/POST送信なし。入力はUTF-8で2953バイト以内（訂正レベル等によりさらに短い上限）。 |
| 6 bcrypt負荷 | bcrypt形式60文字、cost 12以下だけを検証。Argon2等の別方式・高costは実行前に拒否。 |
| 7 bcrypt入力長 | 生成/検証とも平文72バイト以内。マルチバイト文字もバイト数で判定。NULを拒否。PHPのハッシュ処理の例外も捕捉。 |
| 8 bcrypt低cost | 通常生成はcost 10〜12。明示的な検証用途モードだけ4〜9も許可し、実用へ流用しない案内を表示。 |
| 9 コメント/IP拒否 | 通常スパムはIPを拒否しない。スパム＋拒否はユーザー別・10分有効の確認情報を使い、対象IPを提示後、権限と対象の変更を再確認して実行。許可リストを優先し、操作中IPを保護。新規拒否は初期24時間、1時間〜30日の期限付き。既存の期限なし登録は保持。 |
| 10 置換結果 | キャプチャ参照を巨大な文字列へ連結する前に、HTMLエスケープ/改行の展開後サイズを計測。記事全体200万文字と展開処理20万単位の上限。空キャプチャの大量展開も制限。超過は本文を変更せず案内。 |

保持・移行処理はWP-Cronを利用します。無効化している環境では外部CronからWordPressのCronを実行してください。期限判定と保存件数の制限はCronだけに依存しません。機能を無効にしている間は同機能の定期処理も実行しません。

アクセスログを削除・間引きするため、投稿データの閲覧数も保存されている範囲の参考値になります。従来の全履歴を残す用途とは仕様が変わります。既存DB内の秘密情報の除去は移行完了まで段階的に進みます。既に外部へ出力したCSVやバックアップは、この移行の対象外です。

## 検証

隔離したWordPress/MariaDBの新規テストDBを使用し、公開サイトのDB・ファイルには接続しません。テストDBは終了時に削除します。PHP 8.2.12、MariaDB 10.4.32、同梱テスト用WordPress、Chromeで検証。

- `php -n tests/maintenance.php`：116項目。CSV保護、日時、bcryptの入力復元、処理フック、HTTPステータス、更新処理。
- `php -n tests/search-replace.php`：84項目。検索・置換・復元・権限の既存回帰。
- `tests/security-wordpress.php`：75項目。実DBの記録上限/競合ロック、記録頻度、旧ログ保護/消去、保持期限、bcrypt入力/方式/cost、SSRFと転送拒否、取得上限、XML制限、スパムとIP拒否の分離、確認トークン、許可リスト、期限、権限/nonce。
- `tests/editor-search-engine.cjs`：48項目。文字列検索とHTML保持の回帰。
- `tests/editor-search-regex.cjs`：46項目。正規表現・Worker中止・Undo・巨大置換時の本文保持。
- `tests/security-browser.cjs`：17項目。実際のQR画面から日本語/絵文字/Wi-Fi情報を生成して別ライブラリで復号、通信ゼロ、ローカルPNG、置換サイズ/空キャプチャの展開制限。
- 全配布PHP/JSの構文検査、配布ZIP内の全ファイルと作業ファイルのバイト一致を確認。

ブラウザテストは `WPHM_NODE_MODULES` にPlaywrightとjsQRのあるnode_modulesを指定します。WordPressテストは既存の `.wphm-test/wordpress` と、ループバック33077の専用MariaDBが必要です。PHPではmysqli/mbstring/openssl/curlを有効にします。テスト環境・認証情報・画面画像は配布ZIPに含めません。

## 配布

バージョンは0.9.5です。`python tests/build-release.py` で `releases/0.9.5/wp-helpers-multi.zip` を生成します。GitHub Releaseには同じ内容を `wp-helpers-multi-0.9.5.zip` として添付します。専用更新サーバーへ配置する場合はZIPを先に、update.jsonを最後に配置します。
