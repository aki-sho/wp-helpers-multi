# v0.10.0 セキュリティチェックの拡充

## 10項目と共通候補への対応

この機能は設定・既存イベント・公開メタデータを確認する機能です。攻撃、認証試行、ファイル送信・実行、パスワードの解析、自動遮断・自動修正は行いません。表示した範囲の設定上のリスクと、観測した文字列・件数、既知脆弱性の影響版候補を区別します。

| 項目 | 実装・改修内容 | 確認範囲の限界 |
| --- | --- | --- |
| 1 ブルートフォース | 認証失敗・パスワード段階の成功を集計。1分20失敗以上、または共有枠で5分10失敗以上を注意表示。Limit Login Attempts / Reloadedの登録中フィルターと実設定を読み取る | 全認証経路、除外設定、ネットワーク側の制限は未確認。低は読めた試行制限設定だけの評価 |
| 2 クレデンシャルスタッフィング | Two-Factorの公開メソッドで確認範囲の管理者の要求設定を取得。5分の共有枠で5失敗以上の後のパスワード成功候補と、XML-RPC・アプリケーションパスワード設定を表示 | パスワード使い回し・漏えい照合は行わない。wp_loginは2FA前を含む。SSO・独自認証・XML-RPC成功などの最終成否や、全経路への2FA強制は未確認 |
| 3 SQLインジェクション | URLパスに加え、クエリ・POSTの非機密項目を長さ・深さ・要素数で制限して分類。ログには分類の件数のみ保存。本プラグインのSQL値パラメータ・識別子・ソート許可リストを監査 | SQL文字列の観測は攻撃成立を意味しない。他製品のコードは未監査 |
| 4 XSS | 公開登録の初期ロールに加え、既存ユーザーの実効HTML権限とカスタムロールの設定を表示。全ツールの管理出力・JS引渡しを監査 | 独自会員フォームや他製品の出力は未監査。権限の存在だけでXSS成立と判定しない |
| 5 DDoS | WordPress到達通信をボット除外なしで分単位に集計。1分600件以上、または24時間で5xx 20件以上を注意表示。Cloudflareの任意の読取り連携を実装 | PHP到達前のキャッシュ・回線・遮断通信はローカル集計に含まれない。CDN統計を取得できてもDDoS耐性を証明しない |
| 6 CSRF | ダッシュボード設定、文字サイズ、ログ削除/IP操作、コメント操作、リンク点検、URL収集、検索置換、セキュリティ再チェック・設定の受付を監査。状態変更処理のPOST制限を補強 | nonce・権限・メソッドの検証は本プラグインの対象処理について確認。他製品は未監査 |
| 7 RCE | 現在の管理者以外の実効コード編集・プラグイン/テーマ追加権限、有効な既知のコード追加ツールも確認。PHP上流サポート・権限設定・既知脆弱性の根拠を分離 | 提供元PHPパッチは申告と根拠を別表示。サポート切れやコード編集権限からRCE成立は断定しない |
| 8 アップロード | 現在の利用者の許可形式・最大サイズ、実行形式の許可、アップロード先のスクリプト形式、禁止記述の候補を制限付きで読取り。サーバー情報の申告欄を実装 | ファイルの悪意は検査しない。禁止記述の存在から実効設定は断定しない。公開AJAXの件数から匿名アップロード可否を推測しない |
| 9 脆弱性悪用 | WPVulnerabilityの製品名・版範囲を照合し、影響条件・修正版の目安・CVSS条件・CVE等の情報源を表示。CWEがある候補は対応する攻撃項目にも反映 | 独自配布・同名・改名製品、データの欠落、未知の脆弱性、実際の成立・侵害は未確認。MU/ドロップインは一覧化し照合未対応として数える |
| 10 トラバーサル | 入力分類を拡張。本プラグインの固定読込み・ファイル参照を監査。新しい保存先読取りは固定起点、実パスの境界、シンボリックリンク除外を確認 | 他製品のダウンロード・ファイル保存・展開は未監査。../の検出はファイル読取り成立を意味しない |
| 共通1 判定根拠 | コア・PHP・プラグイン・テーマの版ごとに公式照会の根拠を24時間保持。5分の画面キャッシュ切れや別製品の追加でコアの高判定を消さない | 期限切れや照会失敗は明示して未確認にする。更新情報の取得と安全性の証明は別 |
| 共通2 観測漏れ | 一般アクセスログとは別の固定枠で集計し、User-Agentだけによる除外を廃止 | PHP到達前の通信や機能無効期間は観測できない |
| 共通3 未計測表示 | 未取得と観測0件を分離。開始日時・観測された時間・抽出/分類/計数上限を表示 | 通信がない分と停止中の分を推測で埋めない |
| 共通4 負荷制御 | 20秒の最短再実行間隔、全外部照会の25秒予算、各要求3秒・1MiB・転送なし、35秒のブラウザ待機期限、所有者付き90秒の期限付き排他制御 | DNSや進行中の要求の終了はOS依存。ブラウザ停止はPHP処理の強制停止ではない。DBのGET_LOCKに依存しない |
| 共通5 環境検証 | 現行・最低対応のWordPress/PHP、実ネットワークの2サイト、外部キャッシュ読取り分岐、障害・不正応答・排他・無効時の分離を検証 | 外部キャッシュはWordPress APIの読取り経路をテスト。全ホスティングや全CDNプランを実機検証したものではない |

## 監査の根拠

`tools/security_check/audit.json` は今回の配布時にレビューしたPHP/JSの版とSHA-256を記録します。CRLF/LFだけを正規化して、Windowsの配布ZIPとGitから取得したソースの両方を扱います。監査対象は本体・全ツールのPHPと自作JS（vendorライブラリを除く）で、SQL、出力、状態変更受付、ファイル参照を確認しました。画面では現在のファイルとの一致を確認します。変更・欠落があればこの監査を根拠とする低判定を使いません。署名付きの改ざん検知や第三者コード全体の自動静的解析ではありません。ファイル一致は未知の欠陥がない証明ではありません。

低判定の確認範囲は各行に明示します。低には、本プラグインの監査対象処理の一致、確認できたログイン制限設定、PHP標準アップロード受信が無効である経路を含みます。サイト全体の耐性は別に未確認です。

## 計測・保存・プライバシー

機能有効時に管理者が画面を開くと専用集計表を準備します。公開リクエストは表を新規作成しません。その後はinit・認証フックから集計し、PHP終了時にHTTPステータスを反映します。一般のアクセスログ機能や元のログには手を加えません。機能を無効にすると認証・通信の観測フックも読み込みません。

- 通信の分単位リング1,440枠と、認証の共有枠128個で最大1,568行。各計数は60,000で飽和させ、上限到達を表示。
- 認証集中は日別salt付きHMACで共有枠を選択。HMAC・IP・利用者名もDBには保存しない。枠の衝突があるため集中や失敗後成功は概数。
- 分類はパスとGET/POSTの値のうち最大64要素・深さ3・合計8KiB・1値1KiB。password/pwd/token/nonce/auth/secret/cookie/session等のキーは分類しない。JSON本文・ファイル内容は取得しない。
- SQL/HTML風文字列・相対パス記号の分類件数だけを保存。入力本文、URL、認証情報、Cookie、メールアドレス、ファイル内容を保存・外送しない。
- 有効な直近24時間の枠だけを集計。期限切れは固定枠の再利用とWP-Cronで整理。Cron停止中は整理が遅れるが保存行数は増えない。
- 権限確認は最大200利用者・100役割、保存先読取りは最大40ディレクトリ・500項目。リンクは追わず、.htaccessは最大64KiB。上限・読取り不能を明示。

## 外部照会と連携設定

初回表示は外部通信を開始しません。再チェック時の送信先は固定のHTTPS APIのみです。Cookieを送らず、証明書検証を維持し、転送先を追いません。失敗・過大・不正JSON・別製品の応答は未確認にします。

- WordPress.org：コア版、PHP版、公開対象のプラグイン/テーマの名称・版等を照会。独自Update URIの製品とPlugin/Theme URIを送信対象から除外。通常の更新通知のキャッシュは上書きしない。
- WPVulnerability：初期状態で有効、設定画面から無効化可能。公開APIへ製品識別名（コアは版）を照会。プラグイン/テーマの版比較はサイト内で実施。1回8製品まで、続きは次回へ。24時間の製品・版別キャッシュは最大500件・合計2MiB、1製品32KiB。表示候補は1製品20件・全体100件に制限し、省略条件は未確認として数える。異なる版・期限切れは未確認。不明な比較演算子や欠落情報で安全とは判断しない。
- Cloudflare：未設定時は通信なし。Zone Read・Analytics Read・Zone WAF Readのゾーン限定トークンを設定。ゾーンのドメインがサイトと一致することを先に確認し、直近の完了した24時間のHTTP集計と有効な管理WAF呼出ルールを読み取る。GraphQLのPOSTも統計の読取り専用。権限・プラン・取得不能な部分は未確認。設定変更APIは使用しない。
- CloudflareトークンはWordPress salt由来の鍵とAES-256-GCMで暗号化。OpenSSL非対応時は平文保存せず拒否。フォームには再表示せず、空欄で保持・明示削除に対応。レポートやキャッシュにトークンを含めない。
- 管理者申告：アップロード先の実行禁止・提供元PHP修正・根拠を記録。7日で期限切れ。自動取得の根拠や低判定に置き換えない。

Two-Factorは現在の要求条件での公開メソッドの戻り値を参照します。プロバイダーエラーは未確認とし、インストールされているだけで有効とは扱いません。ログイン制限は対応する実フィルターと設定が読めた場合のみ採用します。独自の連携は信頼されたローカルコードの `wphm_security_auth_facts` フィルターで、制限名・回数・秒を提供できます。

## 検証方法

`tests/security-check-wordpress.php` と同梱のextended/multisite検証は、隔離したMariaDBに一時データベースを作成して破棄します。APIの成功・失敗・不正JSON・サイズ超過・転送・別製品・別ゾーンは固定HTTP応答を使います。攻撃・実ログイン・ファイル実行は行いません。Cloudflareの実アカウントや実運用サイトでの診断結果ではありません。

現行環境はWordPress 7.0 / PHP 8.2.12、最低対応環境は公式配布のWordPress 6.0 / PHP 7.4.33を使用。マルチサイトはWordPressの実ネットワークを別プロセスで初期化して2サイトを作成し、サイトごとの権限・集計・排他を確認します。外部キャッシュ分岐はWordPressのキャッシュAPIを使って検証します。

Chromeの画面検証は、ネイティブWordPressが描画した固定データのHTMLと同梱JSを使用。10行、4状態、理由・範囲、再チェック、エラー・不正JSON・タイムアウトからの復旧、設定フォーム・キー非表示、モバイル幅を確認します。画面には固定データと明示します。

既存機能の回帰テストも実施します。ZIP作成時は展開対象の全ファイルを作業ファイルと照合し、公開後もGitHubから再取得してSHA-256と内容を比較します。公開前の実行結果はリリース説明に記載します。
