# セキュリティチェック 0.11.1の改修と検証

## 表示と案内

場所のタグは `（WordPress内）` `（サーバー側）` `（外部サービス）` の3種類だけに統一する。複数の場合は別々のタグを使い、「確認先：」「／参考」などの語句を混ぜない。取得状況は状態バッジと説明で区別する。公開応答から設定元を特定したとは扱わない。

未選択・未取得・取得失敗・確認範囲外の項目は「理由」「次の操作」を表示する。取得済みの場合に使う値・説明を未選択の行に流用しない。接続IDやキーの不足、API認証・権限・通信の失敗、未対応の項目、分割読取り、記録不足を区別する。静的な設定の未取得は「未確認」とし、一律に「計測中」と表示しない。参照できる集計記録がある場合の不足だけを「記録不足」とし、期間・件数と再チェックの操作を示す。

ログイン試行制限は、既存の機能・サーバー・外部サービスの設定を読む項目のままとする。ログインを制限・遮断する新機能は追加しない。実際の防御設定と、このプラグインで比較する回数・期間等の判定基準を区別する。ローカルPHP情報とcPanelのModSecurity読取りから制限値を取得できるとは案内しない。設定値や設定画面を特定できない場合もそのまま明記し、未取得だけで防御設定がないとは判断しない。

PHP上流サポートの照合は「公式の更新情報と照合する」へ案内する。公開応答のCookieや、別のコード点検が必要な項目に、無関係なサーバー・CDNの接続情報の不足を混ぜない。自動読取りの対象外は、設定欄を埋めたり待ったりするだけで確認済みになるとは案内しない。

20項目の折りたたみ、横棒、分類・結果の絞込み、再チェック後の開閉・絞込み保持を維持する。案内は既存の確認項目内に置き、接続欄・照合結果へのリンクを付ける。照合結果へのリンクでは詳細も開く。

## 配布時の情報

リンク点検のサイト固有の誤リンク初期値を空欄にし、正しいホストの初期値は導入したサイトのURLから取得する。保存済みの設定は書き換えない。

更新情報JSONのHTTP取得には `WP-Helpers-Multi/版番号` をUser-Agentとして指定し、WordPress標準のサイトURL入りUser-Agentを使わない。この変更は更新JSONの取得が対象で、送信元IPやWordPress本体のZIP取得等の別の通信を隠す機能ではない。更新用の配布サーバーのURLと、公開アドバイザリを確認する自プラグインのリポジトリ名は用途に必要な公開設定として残る。

配布ZIP・ソース内容とGitの投稿者情報は別に確認する。ZIPを差し替えても、公開済みのGit履歴の投稿者情報は削除されない。

## 検証

実サイトへの攻撃や実契約の認証情報を使わず、隔離したWordPress・MariaDBと固定API応答を使用する。

| 検証 | 成功件数 |
|---|---:|
| WordPress 7.0 / PHP 8.2.12 セキュリティチェック統合 | 1,083 |
| WordPress 6.0 / PHP 7.4 セキュリティチェック統合 | 1,083 |
| マルチサイト・無効時・フロント側の分離 | 32 |
| 既存セキュリティ回帰 | 75 |
| 投稿データ・サイト内URL一覧 | 357 |
| 検索置換の純粋処理・WordPress統合 | 114 |
| 保守機能の純粋処理・WordPress統合 | 148 |
| 実HTTP応答・エディターの権限と読込み | 77 |

合計2,969件。途中の失敗・再実行・単独の追加検証は重複加算しない。タグの完全一致、未選択の説明の残留防止、項目に対応する設定場所、公開応答に無関係な接続不足を混ぜないこと、原文エラー・秘密値の非表示、出力エスケープ、ログイン制限フックを追加しないこと、更新JSONの実際のHTTP引数を確認する。

ブラウザでは全20項目の開閉、3種類のタグ、未確認の行の理由と次の操作、分類と結果の組合せ、再チェック後の保持、接続欄の開閉を確認する。320px幅で開いた接続欄と説明に横はみ出しがないこと、パスワード欄が空であることも確認する。表示値は試験データであり、実サイトの判定結果ではない。

PHP 74ファイルを8.2と7.4、JavaScript 14ファイルをNodeで構文確認する。実行ファイル87件のSHA-256を点検記録と照合し、配布ZIPのCRC・構成・全ファイルのバイト一致・秘密ファイルの混入を確認する。配布物のSHA-256は `releases/0.11.1/SHA256SUMS.txt` を参照。

変更箇所と既存の権限・nonce・SQL・出力・HTTP・ファイル境界の回帰を点検する。未知の欠陥、他製品、サイト全体の安全を保証する検証ではない。
