# v0.9.6：投稿データの件数表示・サイト内URL一覧

## 投稿データ

「アイキャッチ」の直後に「記事内画像数」「記事内リンク数」を追加しました。表示項目の選択、数値での昇順/降順、CSV出力に反映します。カテゴリ別の行が複数になっても、同じ記事の値を使います。

画像数は保存本文の `img`、リンク数は `href` を持つ `a` タグの件数です。`picture` の候補画像や `srcset` の候補数は画像の枚数に加算しません。本文に挿入していないアイキャッチや、ショートコード/動的ブロック/JavaScriptで表示時に追加される要素は含みません。記事表示処理やスクリプトを実行せず集計します。

## サイト内URL一覧

目的は、サイト内で見つかったURLから固定ページ・投稿記事のURLだけを除外し、残りを種類に関係なく一覧表示することです。カテゴリ等に対象を限定する機能ではありません。画像・ファイル・独自パス・カスタム投稿タイプ等も、発見したサイト内URLとして記録します。

- 管理画面の新しい「サイト内URL一覧」で「収集開始・再収集」を押します。WP Helpers Multiのダッシュボードから有効/無効を切り替えられます。
- WordPressに登録されたURL、公開/継承状態の保存本文、メニューやブロックのURL属性、サイトマップ、公開ページ、CSS/JSON/XMLの参照を収集します。投稿・固定ページも発見元として読み取りますが、それらのURLは結果のURL列とCSVから除外します。
- 同一サイトのホストにあるHTTP/HTTPS URLを収集し、URL・発見元・発見方法・HTTPステータス・確認状態を表示します。HTTPエラーのURLも、発見したURLとして残します。
- 重複は除き、フラグメントは同じリソースとして扱います。認証情報付きURLは受け付けず、認証用と判定したクエリ値は伏字にします。通常のクエリは記録します。
- 管理/ログイン/パラメータ付きURL、一般的な画像やバイナリ、非標準ポート等は一覧へ記録し、自動巡回しません。通常のページやCSS等は安全なHTTP APIで取得し、内部IP・外部サイトへの転送を拒否します。転送先は別URLとして検証します。
- 最大10,000URL、最大2,000回の通信。1応答1MiB、HTTPのタイムアウト3秒、1バッチ最大3取得です。DNS解決時間自体はOSに依存します。本文の解析も1MiB、抽出は1文書2,000URLまでです。DTDを含むXMLは解析しません。
- 制限に達した場合は収集済みの範囲であることを表示します。ネットワーク通信を省略したURLと、取得失敗したURLも区別して残します。
- 一時停止・再開が可能です。画面を閉じると現在のバッチ終了後に停止します。バックグラウンドの定期巡回は行いません。再収集では確認後に前回の結果を置き換えます。
- URL/発見元で検索でき、CSVも現在の検索条件に従います。CSVは既存の数式対策を適用し、200行ずつ出力します。

サイトやプラグインが公開していないURL、未リンクのURL、ログイン後だけのURL、JavaScriptの実行が必要なURLをすべて列挙するものではありません。収集できたURLの一覧です。新しいテーブルは `{$wpdb->prefix}wphm_site_urls`、状態は `wphm_site_urls_state` に保存します。

## 検証

2026-11-01、PHP 8.2.12・MariaDB 10.4.32・隔離したWordPress・Chromeで確認。新規の専用テストDBだけを使用し、終了時に削除します。公開サイトや既存ブラウザのログイン情報は使用しません。

- `tests/site-data-wordpress.php`：76項目。本文タグ件数、アイキャッチの除外、列順、数値ソート、CSV項目、相対URL/HTML base、投稿/固定ページとクエリ変種の除外、カスタム投稿/画像/PDF/未知のパス/メニュー/サイトマップ/CSS/JSONの収集、重複、通信上限の仕組み、転送先の拒否、検索、権限・nonce・機能無効化。
- `tests/site-data-browser.cjs`：18項目。実際にWordPressで描画した画面の列順・選択・ソート・CSVリンク、新機能の検索・一時停止・再開・完了・モバイル表示・JavaScriptエラーを確認。収集UIのHTTP応答は隔離サーバーで制御します。収集処理と権限は上記のWordPress/MariaDBテストで確認します。
- 既存回帰：`tests/maintenance.php` 116項目、`tests/search-replace.php` 84項目、`tests/security-wordpress.php` 75項目、`tests/editor-search-engine.cjs` 48項目、`tests/editor-search-regex.cjs` 46項目、`tests/security-browser.cjs` 17項目。
- 全配布PHP/JSの構文検査、配布ZIP内のファイル一致を確認します。

WordPressテストは `.wphm-test/wordpress` とループバック33077の専用MariaDBが必要です。PHPのmysqli/mbstring/openssl/curlを有効にします。ブラウザテストは `WPHM_NODE_MODULES` にPlaywright/jsQRのあるnode_modulesを指定します。テストDB・認証情報・画面画像は配布しません。

## 配布

`python tests/build-release.py` で `releases/0.9.6/wp-helpers-multi.zip` を生成します。GitHub Releaseには同じ内容の `wp-helpers-multi-0.9.6.zip` を添付します。専用更新サーバーへはZIPを先に、`update.json` を最後に配置してください。
