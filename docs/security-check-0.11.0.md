# v0.11.0：20項目のセキュリティチェック

既存1〜10の番号を維持し、11〜20を追加した。全項目を折りたたみ、分類・結果による絞込み、一括で閉じる操作を追加した。取得元の詳しいカードも折りたたみ、確認項目を先に読める構成にした。再チェック後も項目の開閉・分類・結果の絞込みを保持する。

## 公開応答の取得

管理者別の「公開応答を確認する」は初期状態では未選択。選択して再チェックしたときだけ、WordPressに設定された公開トップと標準ログインページへ未ログインの通常GETを行う。入力欄から任意URL・パス・関数を指定する機能はない。通常表示・自動続行は5分以内の管理者・サイト・設定URLに対応するメタ情報を参照し、暗黙に再接続しない。

- HTTP/HTTPSの標準ポートだけを許可し、認証情報・クエリ・フラグメント付きURLを拒否する。
- 全DNS回答を公開IPとして検証し、cURLの接続先IPを固定する。1回の確認内で名前解決を共有し、IPを再検証する。
- TLSの証明書・ホスト名検証を有効にし、接続先IP・URLと一致するcURL情報だけを採用する。プロキシ経由や接続IPを固定できない転送方式は使用しない。
- 自動転送を無効にし、同じ設定サイトの許可したオリジンのみ最大2段階追跡する。サイト外、クエリ等の付いた転送、HTTPSからHTTPへの転送は追わない。計6通信まで。
- HTTP処理は共通6秒枠・各2.5秒以内で、既存の全体期限も確認する。名前解決自体の時間はOS・DNS環境に依存する。
- 読み取る本文は最大1KiBで廃棄し、ヘッダーは64種類・値20件・1値8KiB・全体32KiBまで。改行や入れ子等の不正形式は採用しない。
- cURLの一時フックは対象URLだけに適用し、例外時もfinallyで解除する。

既存の認証Cookie・APIキーは送らない。Cookie値、ヘッダー全文、本文、証明書全文、転送先の秘密クエリを結果・キャッシュ・画面に保存しない。保持するのは件数・真偽値・固定分類・時刻だけで、未知のエラー本文も表示しない。公開応答のGETは、既存のアクセスログや統計に通常アクセスとして記録される場合がある。

## 判定の範囲

横棒は達成率ではなく、確認項目で取得できた範囲のリスク。要対応は高、要確認は中、必要な根拠が不足すれば未確認。参考情報は確認不足や既知脆弱性の指摘を打ち消さない。新しい分類に関連する既知脆弱性も、表示件数を超えたCWE情報を含めて反映する。

次は別の点検・連携が必要で、自動的に確認済みにはしない。

- 他のテーマ・プラグイン・本体すべてのSQL、権限、CSRF、HTTP、パス、転送処理の監査。
- 独自認証Cookie・SSO等への適用、全利用者のセッション、実際の認証後の画面やAPIの応答。
- TLSの全許可方式、別の配信拠点の証明書、自動更新の成否。
- Originや認証状態で変わるCORS、CDNの全キャッシュキー、認証後の個人別応答との分離。
- 全配布物の署名・チェックサム・配布元の信頼性、未知の脆弱性・侵害の有無。
- 全ファイルの公開状態。固定位置の存在候補は公開アクセス可能の証明ではなく、内容は読まない。シンボリックリンクは追わない。

WordPress標準Cookieの方針は標準実装と関連フックの状態に基づく。独自の変更があれば未確認を維持する。Cookieを新規発行したりログイン試行を行ったりしない。セッションは現在の管理者だけを最大64KiB・100件で集計し、識別子・IP・端末名は結果へ残さない。

最終の自動検証は合計2,845件。途中の実行や重複する単独試験、構文・画面確認はこの合計に加算していない。各追加項目について正常・異常・不足する根拠を検証し、未取得を安全にしないことを確認した。公開IP検証、TLS、転送、時間・ヘッダー上限、秘密値の破棄、管理者・URL・時刻を結び付けたキャッシュも検証した。実契約のサーバーやAPIキーは使用していない。

実際のPHPで生成した画面と同じCSS・JavaScriptをローカルブラウザで操作し、全20項目の開閉、76個の設定場所ラベル、取得元詳細の初期折りたたみ、分類と結果の組合せ、再チェック後の絞込み・開閉保持、一括で閉じる操作を確認した。利用者だけの自動続行・一時停止・再開、不正な続行応答で前の20項目を保持して再操作できることも確認した。320px・736px幅で設定欄と開いた詳細に横はみ出しがなく、確認時のJavaScriptエラーは0件。画面のデータは隔離試験の固定応答であり、実サイトの測定値ではない。

プラグイン全体について、管理操作の権限・nonce・状態変更メソッド、SQLの値と識別子、出力処理、CSV、HTTP取得先と転送、固定起点のファイル参照、件数・時間・サイズ上限を再確認した。未知の欠陥が一切ないことを保証する点検ではない。

PHP 73ファイルをPHP 8.2と7.4、JavaScript 14ファイルをNodeで構文確認した。点検対象の実行ファイル86件は `tools/security_check/audit.json` のSHA-256と一致。配布ZIPは103ファイルについて、CRC・フォルダ構成・作業ツリーとの全バイト一致を確認した。配布物のSHA-256は `releases/0.11.0/SHA256SUMS.txt` を参照。
