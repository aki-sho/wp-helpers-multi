# 正規表現の検索・置換（v0.9.4）

## 変更内容

投稿・固定ページの編集画面内のパネルに「正規表現（.*）」を追加しました。初期状態は従来の文字列検索です。オンにするとJavaScriptの正規表現として検索します。

`\d+\.[ \t]*` を検索し、置換欄を空にすると、本文中の `1. `・`12. ` などの半角数字とピリオド、続くスペース・タブを削除できます。式をスラッシュで囲む必要はありません。

置換では `$1`・`$2`・`$<name>` のキャプチャ、`$&`／`$0` の一致全体、`$$` のドル記号に対応します。置換結果も文章としてHTMLエスケープし、リンク先・タグ属性・ブロック設定を保持します。正規表現をオフにした場合は、`$1` なども入力した文字そのものです。

## 実行と中止

正規表現はWorker内で処理し、処理開始から1.5秒で応答しない場合はWorkerを終了して案内します。Workerのファイル読み込みは別に最大8秒待ちます。検索語の変更・パネルを閉じる操作でも古い検索を中止します。

検索中は置換ボタンを無効にします。変更された本文へ古い検索結果を適用せず、現在の内容との照合を維持します。装飾の強調表示はWorkerが返した文章中の位置に基づき、本文へ検索用のタグを追加しません。

無効な式や空文字に一致する式はエラーにし、部分的に置換しません。本文200万文字、一致5,000件の上限は従来どおりです。キャプチャする文字数にも上限を設けています。

## 対象の範囲

各ブロックの文章・段落単位で検索します。`^`／`$` は行頭・行末に対応します。ブロックをまたぐ検索や、空文字一致による挿入は対象外です。

番号付きリストの自動採番は本文の文字列ではないため、この式で削除する対象にはなりません。通常の文字として入力された半角数字とピリオドが対象です。コード領域・同期パターン・登録済みショートコード・未対応の独自ブロックの扱いは従来どおりです。
