# v0.11.0 配布ファイル

セキュリティチェックを20項目へ拡張しました。[項目別の改修と検証](../../docs/security-check-0.11.0.md) を参照してください。

GitHub Releasesの `wp-helpers-multi-0.11.0.zip` をWordPressの「プラグインのアップロード」から上書き更新できます。公開応答の確認は管理者が任意で選択します。契約情報・APIキーを開発者に渡す必要はありません。

専用配布サーバーにはZIPを先に `https://plugin.pretty-cute.info/wp-helpers-multi/wp-helpers-multi.zip` へ配置し、最後に同じディレクトリへ `update.json` を配置してください。GitHubへの公開だけでは配布サーバー・WordPress実サイトは更新されません。
