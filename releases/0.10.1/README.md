# v0.10.1 配布ファイル

セキュリティチェックの①②⑤⑧⑨に、確認項目・設定方法と確認範囲に対する判定を追加しました。既知脆弱性の照合は再チェック一度で自動続行します。未確認の棒も灰色と文字で表示します。[改修内容と検証](../../docs/security-check-0.10.1.md) に各項目の条件・設定・安全性を記載しています。

GitHub Releasesの `wp-helpers-multi-0.10.1.zip` は、WordPressの「プラグインのアップロード」から上書き更新できます。

専用配布サーバーへ反映する場合は、このフォルダの `wp-helpers-multi.zip` を先に `https://plugin.pretty-cute.info/wp-helpers-multi/wp-helpers-multi.zip` に配置し、最後に `update.json` を同ディレクトリへ配置してください。GitHubへの公開だけでは、専用配布サーバーやWordPress実サイトは更新されません。

認証制限・追加認証は対応する機能の設定を読み取ります。Cloudflareは任意の連携です。照合対象外・取得失敗・記録待ちを区別し、未知の脆弱性や侵害の有無は推測しません。攻撃を伴う診断や認証設定の自動変更は行いません。
