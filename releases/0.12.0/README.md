# WP Helpers Multi 0.12.0

GitHub Releaseのインストール用ZIPは `wp-helpers-multi-0.12.0.zip` です。

WordPress設置先を自動表示し、設定・ファイル・対応形式の保存コードを範囲指定して分割読取りします。20項目を設定状態の内訳と確認先で表示します。記述の検出だけで対策を有効とは判定しません。既存の防御設定は変更しません。

専用配布サーバーへ反映する場合は、ZIPを `wp-helpers-multi.zip` として既存の更新用ディレクトリに配置し、`update.json` も同時に更新してください。GitHubへの公開だけでは専用配布サーバーや導入済みWordPressは更新されません。

対象範囲・上限・検証記録はリポジトリの `docs/security-check-0.12.0.md` を参照してください。
