# v0.9.4：正規表現の検索・置換

## 配布サーバーへの配置と更新

1. 専用配布サーバーの `plugin-server/wp-helpers-multi/` 直下へ、このフォルダの `wp-helpers-multi.zip` を上書きします。
2. 転送完了後、同じ場所の `update.json` を上書きします。
3. WordPressの「ダッシュボード → 更新 → 再確認」を押し、WP Helpers Multiを更新します。
4. プラグイン一覧がv0.9.4になったことを確認します。

ZIPとJSONは `packages` の中には配置しません。WordPress側のPHPファイルを手動で差し替える必要はありません。v0.9.3以降の「再確認」は専用の更新情報キャッシュも無視して問い合わせます。

## 正規表現の使い方

1. 投稿・固定ページの編集画面を開き直し、「検索・置換」を押します。
2. 「正規表現（.*）」をオンにします。
3. 検索欄へ `\d+\.[ \t]*` を入力します。`1. `・`12. ` のような半角の番号を検索できます。
4. 番号を削除する場合は置換欄を空にし、「この箇所を置換」または「すべて置換」を押します。
5. 内容を確認し、WordPress標準の「更新」「下書き保存」で保存します。

置換には `$1`・`$2`・`$<name>` のキャプチャ、`$&`／`$0` の一致全体、`$$` のドル記号を使用できます。正規表現をオフにすると、従来の文字列検索です。

式はJavaScript形式です。空文字に一致する式は対象外です。番号付きリストの自動採番は本文の文字列ではないため検索対象になりません。長時間かかる式は中止してメッセージを表示します。
