# v0.10.3 配布ファイル

6候補の改修・個別確認と、プラグイン全体の再確認を行いました。[改修・設定・検証](../../docs/security-check-0.10.3.md) を参照してください。

利用者が管理画面で接続先を設定します。開発者に契約情報やAPIキーを渡す必要はありません。未対応のサービス・設定は未確認と表示します。

GitHub Releasesの `wp-helpers-multi-0.10.3.zip` は、WordPressの「プラグインのアップロード」から上書き更新できます。

専用配布サーバーにはZIPを先に `https://plugin.pretty-cute.info/wp-helpers-multi/wp-helpers-multi.zip` へ配置し、最後に同じディレクトリへ `update.json` を配置してください。GitHubへの公開だけでは配布サーバー・WordPress実サイトは更新されません。
