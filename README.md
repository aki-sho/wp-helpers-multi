## 概要
**WP Helpers Multi** は、WordPress運用で「ちょっと欲しい」を集めたユーティリティ集です。  
現在、以下の機能を同梱しています。

- サイト運営者向けリンク集
- QRコード生成
- 電卓
- bcrypt ヘルパー
- パスワード生成
- タイマー
- リンク点検
- アクセスログ
- 投稿データ
- コメント管理
- 記事検索・置換

> 目的：学習（プラグイン開発・更新配布）と、日々の運用効率を少しずつ上げること。

---

## 特徴（v0.9）
- ✅ 管理画面にツールを集約（“使いたい時にすぐ”）
- ✅ ダッシュボードから機能ごとに有効・無効を切り替え
- ✅ 無効な機能は左メニューと不要な処理を読み込まない
- ✅ サイト運営でよく使うサービスを工程・カテゴリ別に整理
- ✅ 共通のモダンな管理画面デザイン
- ✅ 小さく始めて拡張しやすい（ツール追加の土台）

---

## 機能一覧（v0.9）
- ✅ **サイトリンク**：構築・制作・運用・収益化で使うサービスへのカテゴリ別リンク集
- ✅ **QRコード生成**：テキスト/URL からQRを作成
- ✅ **電卓**：軽い計算を即実行
- ✅ **bcrypt**：ハッシュ生成・検証（開発/確認用）
- ✅ **パスワード生成**：長さ・文字種を指定して生成
- ✅ **タイマー**：作業・待機に
- ✅ **リンク点検**：URLの到達確認（簡易チェック）
- ✅ **アクセスログ**：アクセス状況の確認、IP拒否・解除、スパムコメント履歴の相互確認
- ✅ **投稿データ**：投稿情報、記事閲覧総数、カテゴリ絞り込み、CSV出力
- ✅ **コメント管理**：コメント状態の管理、対象確認付きの期限付きIP拒否、アクセスログとの相互確認
- ✅ **記事検索・置換**：投稿・固定ページの編集画面内で、未保存の本文も検索・置換。一致箇所の強調表示・前後移動・個別／一括置換・元に戻すに対応

## インストール（2通り）

### 1) GitHub ZIP でインストール
1. GitHub の **Releases** から `wp-helpers-multi.zip` をダウンロード
2. WP管理画面 → **プラグイン** → **新規追加** → **プラグインのアップロード**
3. 有効化

### 2) 専用配布サーバーからの更新（Self-hosted）
初回は配布ZIPをWordPress管理画面からアップロードして有効化します。その後は、本体に設定された `https://plugin.pretty-cute.info/wp-helpers-multi/update.json` を参照して更新通知を表示します。

- 更新ファイルの公開先：`https://plugin.pretty-cute.info/wp-helpers-multi/`
- 配置するもの：
  - `wp-helpers-multi.zip`
  - `update.json`（バージョンや更新情報）

ディレクトリ例：

    https://plugin.pretty-cute.info/wp-helpers-multi/
      ├─ wp-helpers-multi.zip
      └─ update.json

`update.json` の例：

    {
      "name": "WP Helpers Multi",
      "slug": "wp-helpers-multi",
      "version": "0.9.5",
      "download_url": "https://plugin.pretty-cute.info/wp-helpers-multi/wp-helpers-multi.zip",
      "requires": "6.0",
      "requires_php": "7.4",
      "last_updated": "2026-10-31",
      "sections": {
        "description": "Utility toolbox for WordPress admins.",
        "changelog": "- v0.9.5 セキュリティ改修（ログ・リンク点検・QR・bcrypt・IP拒否・置換上限）"
      }
    }

更新時は本体の `Version` と `WPHM_VERSION`、`update.json` の `version` をそろえます。ZIPを先に配置し、最後に `update.json` を公開すると、ダウンロード先の準備が整ってから更新通知が表示されます。ZIP内の最上位フォルダ名は `wp-helpers-multi` を維持してください。

v0.9.1以降の更新情報は正常取得時に6時間キャッシュします。取得に失敗した場合は10分間隔で再試行し、最大7日間保持した直近の正常情報を使用します。正常情報がない場合は更新通知を出しません。プラグイン自身の更新完了時には更新情報キャッシュを解除します。

v0.9.3以降は、プラグイン一覧のWP Helpers Multiの「更新を確認」、または「ダッシュボード → 更新 → 再確認」でキャッシュを無視して再取得できます。通常の画面表示では従来どおりキャッシュを利用します。手動確認は更新権限を持つユーザーに限定し、一覧のリンクではnonceも検証します。通信失敗時は前回の情報を使用したことを明示します。

v0.9.1〜v0.9.2にはこの再確認処理がありません。旧版のキャッシュが残るサイトへv0.9.3を初めて導入する際は、キャッシュの期限切れ後に通常更新するか、配布ZIPをWordPressのプラグインアップロードから一度上書き更新してください。v0.9.3導入後の再確認では待つ必要はありません。

## 使い方
インストール後、WordPress 管理画面に **WP Helpers Multi** のメニューが追加されます。  
ダッシュボードで使用する機能をオンにすると、各ツールを使用できます。記事検索・置換は投稿・固定ページの編集画面内に表示されます。
初期状態ではすべての機能が有効です。

### 記事検索・置換（v0.9.2）
1. 投稿、または固定ページの編集画面を開き、右上の「検索・置換」を押します。
2. 検索する文字を入力すると、編集中の本文内の一致箇所が強調表示されます。「前へ」「次へ」で移動できます。
3. 置換後の文字を入力し、「この箇所を置換」または「すべて置換」を押します。空欄にすると削除します。
4. 「元に戻す」で取り消せます。確認後、通常の「更新」「下書き保存」で保存してください。WordPress標準の自動保存も通常どおり動作します。

対象は今開いている1記事の本文で、新規記事・未保存の編集内容も含みます。検索は日本語・大文字小文字の区別・改行・絵文字・HTMLエンティティに対応する文字列検索です。本文にフォーカスがあるときのCtrl+F／Ctrl+Hでも開けます。検索欄のEnter／Shift+Enterで前後移動、Escで閉じます。改行を入力する場合はAlt+Enterです。

v0.9.4では「正規表現（.*）」をオンにすると、JavaScript形式の正規表現を使用できます。例えば `\d+\.[ \t]*` で `1. `・`12. ` のような半角の番号部分を検索し、置換欄を空にして削除できます。式を `/` で囲む必要はありません。置換では `$1`・`$2` などのキャプチャ、`$<name>` の名前付きキャプチャ、`$&`／`$0` の一致全体、`$$` のドル記号を使用できます。オフのときは従来どおり入力した文字そのものを検索し、置換の `$1` も文字として扱います。

正規表現は各ブロックの文章・段落単位で検索し、`^`／`$` は行頭・行末にも一致します。ブロックをまたぐ検索や、空文字に一致する式による挿入には対応しません。番号付きリストの自動採番は本文の文字ではないため、数字の検索対象にはなりません。正規表現はWorkerで実行し、長時間かかる検索は中止して案内します。

ブロックエディターとクラシックエディター（ビジュアル／テキスト）に対応します。装飾をまたぐ文字も検索でき、HTMLタグ・リンク先・ブロック設定を保持します。置換文字列は文章として扱います。検索の強調表示は保存されません。

標準の段落・見出し・リスト・引用・テーブル・キャプション・ボタンの文章が対象です。コード・カスタムHTML・ショートコード・同期パターン・未対応の独自ブロックは対象外としてパネルに表示します。登録済みショートコード内も変更しません。ブロックエディターのコード表示では、ビジュアル表示へ切り替えて使用します。タイトル・抜粋・URL属性は対象外です。

本文の上限は200万文字、一致箇所は5,000件です。一致上限に達したときは一括置換を隠し、検索語を絞る案内を表示します。

v0.9.0〜v0.9.1の独立した検索画面・一括更新APIは終了しました。以前の履歴データは保持しており、管理者は `admin.php?page=wphm-search-replace` から過去の履歴を参照・復元できます。編集画面内での変更の履歴は、標準のUndo／Redo・リビジョンに従います。

検証手順は [編集画面内の検索・置換の検証](docs/editor-search-testing.md) を参照してください。

### セキュリティ改修（v0.9.5）

- アクセスログは初期値で30日・最大10万件、全体120件/分・IPごと10件/分です。管理画面から変更できます。混雑時は一部を省略するため、閲覧数は記録された範囲の参考値です。IP制限は64個の共有枠で管理し、近い枠のIPも影響する場合があります。
- URL・参照元の認証情報、クエリ、フラグメントは保存しません。既存ログも画面・CSVでは即時に除去し、DB内はWP-Cronで200件ずつ整理します。古いログは1回1,000件ずつ削除します。WP-Cronを無効にしているサイトは外部からCronを実行してください。
- リンク点検は初期設定で自サイトのホストだけを取得します。内部IP・認証情報付きURL・80/443以外のポートは拒否し、転送先にも同じ条件を適用します。1応答1MiB、全体20取得・20秒、XMLのlocは2万件までです。圧縮サイトマップ・DTDは対象外です。DNS解決自体の待ち時間はOSに依存します。別の公開ホストを許可する場合は `wphm_li_allowed_sitemap_hosts` フィルタを使用します。
- QRコードはブラウザ内で生成します。入力内容をWordPressサーバーや外部サービスへ送りません。JavaScriptが必要です。
- bcryptは平文72バイト以内、検証はbcrypt形式・cost 12以下です。通常の生成costは10〜12、明示的な検証用途モードでは4〜9も選べます。旧版で作ったcost 13以上の検証はこのツールでは行いません。
- コメントは「スパムのみ」と「スパム＋IP拒否」を選べます。後者は対象IPを確認して実行します。アクセスログと共通のIP許可リストを優先し、新しいIP拒否には初期値24時間の期限を付けます（1時間〜30日）。操作中の自分のIPは新たに拒否できません。既存の期限なし拒否は保持します。
- 検索・置換は展開後・HTMLエスケープ後のサイズを生成前に確認し、本文200万文字・展開処理20万単位の上限を適用します。

改修項目と検証手順は [v0.9.5の検証](docs/security-0.9.5.md) を参照してください。

### 共通処理の修正（v0.9.1）

アクセスログのCSV出力・削除・IP操作、コメント管理の状態変更、リンク点検の開始・バッチ・リセットは `load-*` フックで管理画面のHTML出力前に処理します。投稿データのCSVは従来の `admin-post.php` から出力し、両CSVでUTF-8 BOMと共通の値保護処理を使用します。数式として解釈される文字列には先頭にアポストロフィを付け、数値型の値は数値のまま出力します。

アクセスログのUNIX時刻はサイトのタイムゾーンで表示し、日付絞り込みも同じタイムゾーンの日の開始・終了を使用します。投稿データの保存済みローカル日時は二重に時差変換しません。

アクセスログは記録対象のフロントリクエスト情報を保持し、PHPの終了処理で最終HTTPステータスとともに保存します。リダイレクト、IP拒否、404、PHP側で処理可能なエラー応答も記録します。PHPが動かない静的配信・ページキャッシュ、REST、AJAX、PHPの起動前に発生する障害は従来どおり対象外です。取得不能なステータスは0（不明）として扱います。以前のログのステータスを遡って修正する処理は行いません。

共通処理の回帰テスト: `php -n tests/maintenance.php`。WordPressとHTTP通信を含む検証内容は `docs/maintenance-0.9.1.md` を参照してください。

**WP Helpers Multi** adds a small toolbox of admin utilities to WordPress.
