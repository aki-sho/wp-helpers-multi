== Changelog ==
= 0.9.9 =

新機能「セキュリティチェック」を追加。ダッシュボードで有効・無効を切り替え可能
10種類の攻撃について設定・更新情報・既存ログを読み取り、確認範囲の低・中・高を色付き横棒で表示。情報不足は未確認として表示
各項目に現在の状態・理由・確認範囲を表示し、再チェックで最新の設定・ログとWordPress公式の版・更新情報を参照
攻撃・ログイン試行・ファイル送信・コード実行・自動修正は行わず、既存のログ・更新通知・設定も変更しない構成

= 0.9.8 =

サイト内URL一覧で、アップロードディレクトリ配下・画像ファイルへの自動転送・添付ファイルページを個別に選択可能に変更
チェックした種類の除外と、チェックした種類だけの収集を切り替え可能に変更。複数選択にも対応
チェックの変更を自動保存し、収集済み一覧・以後の収集・CSVに反映。保存ボタンや再収集は不要
画像への転送を安全なHTTP APIと応答ヘッダーで確認。転送の追跡・HEAD未対応時の小容量GET・未判定件数の表示に対応

= 0.9.7 =

サイト内URL一覧に、収集前に選べるアップロードディレクトリ配下のURL除外設定を追加
ページを離れると発見URLと収集状態を削除。同じページの検索・並び替え・一時停止・CSV出力では保持
確認状態の右にアクセス権限を表示。未ログイン時の応答とWordPress標準管理画面の情報から判定
URL・発見元・発見方法・HTTP・確認状態・アクセス権限の全6列で昇順・降順ソートに対応。CSVにも反映

= 0.9.6 =

投稿データのアイキャッチの隣に記事内画像数・記事内リンク数を追加。並び替え・項目選択・CSVにも対応
サイト内URL一覧を追加。保存本文・WordPress情報・サイトマップ・公開ページからURLを収集し、固定ページ・投稿記事のURLだけを一覧から除外
種類を限定せず、発見元・HTTP・確認状態を表示。検索・CSV・収集の停止/再開に対応

= 0.9.5 =

アクセスログに保持期間・保存件数・記録頻度・文字数の上限を追加
URL・参照元の認証情報、クエリ、フラグメントを保存前に除去し、既存ログも順次整理
リンク点検の取得先・転送先を公開HTTP/HTTPSの許可ホストに制限し、取得量・回数・時間・XMLを制限
QRコードを同梱MITライブラリでブラウザ内生成し、入力内容の外部送信を廃止
bcryptに72バイト制限・検証方式/cost上限・通常生成cost 10以上と低cost検証モードを追加
コメントのスパム指定とIP拒否を分離し、対象確認・許可リスト・期限付き拒否を追加
記事検索・置換で、キャプチャ展開・HTMLエスケープ後のサイズを文字列生成前に検証

= 0.9.4 =

編集画面内の検索・置換に「正規表現（.*）」の切り替えを追加

数字とピリオドなどのパターン検索、行頭・行末、キャプチャグループによる置換に対応

正規表現の検索をWeb Workerで実行し、長時間かかる式を中止できるよう改善

無効な式・空文字に一致する式を画面に表示し、検索中や失敗時の置換を防止

= 0.9.3 =

プラグイン一覧のWP Helpers Multiに「更新を確認」を追加

WordPress標準の「ダッシュボード → 更新 → 再確認」でも専用配布サーバーの更新情報をキャッシュに関係なく再取得するよう修正

取得失敗時は以前の情報を使用したことを明示し、最新の確認成功と区別して表示

管理者の更新権限とnonceを検証し、このプラグインの更新情報のみを再取得

一致箇所の強調表示・前後移動・個別置換・全置換・エディター標準の元に戻すに対応

ブロックエディターとクラシックエディター（ビジュアル／テキスト）に対応し、装飾・HTML属性・リンク先・ブロック設定を保持

置換は編集中の本文へ反映し、公開・保存は通常の更新・下書き保存とWordPress標準の自動保存に従う構成へ変更

従来の独立した検索画面と一括更新APIを終了し、過去の置換履歴の参照・復元を維持

アクセスログのCSV出力・更新処理、コメント管理の更新処理、リンク点検の開始・バッチ・リセットを、管理画面のHTML出力前へ移動
