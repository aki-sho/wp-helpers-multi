== Changelog ==
= 0.9.1 =

アクセスログのCSV出力・更新処理、コメント管理の更新処理、リンク点検の開始・バッチ・リセットを、管理画面のHTML出力前へ移動

bcrypt生成・検証で、引用符とバックスラッシュを含む入力を正しく復元する処理を追加

アクセスログの画面・CSV・日付絞り込みと投稿データの日時を、WordPressのサイトタイムゾーンに統一

アクセスログをリクエスト終了時に保存し、実際のHTTPステータスを記録する構成へ変更

専用配布サーバーの更新情報取得にキャッシュ・失敗時の再試行間隔・直近の正常情報へのフォールバックを追加

Update URIと対応する更新フックを追加し、古い更新通知と反対側の更新状態を解除

投稿データとアクセスログのCSVに共通処理を導入し、数式として解釈される文字列を保護

= 0.9.0 =

投稿・固定ページを対象にした「記事検索・置換」を追加

記事種別・公開状態・記事ID・タイトル・カテゴリの絞り込みと、箇所ごとの差分確認・選択置換に対応

日本語・大文字小文字・複数行・HTMLエンティティに対応する文章モードを追加

HTML属性・ブロック設定・コード・ショートコードを保護し、未対応ブロックと検索上限を表示

置換前後の本文を保存する履歴と、後続編集を検出して上書きを中止する復元処理を追加

管理者権限・記事編集権限・nonce・ユーザー別の検索結果照合・編集ロック・重複実行防止を追加

サイトリンクのキーワード検索と工程ナビゲーションを追加

ダッシュボードに機能ごとの有効・無効切り替えを追加

無効にした機能を左メニューから非表示にし、不要な機能処理を読み込まない構成へ変更

アクセスログとコメント管理の共有IP拒否基盤は、どちらか一方が有効な場合に維持する構成へ変更

ダッシュボード、ツール共通ヘッダー、フォーム、一覧表をモダンな管理画面デザインへ刷新

機能定義とリンクカタログをフィルターで拡張できる構成を追加
